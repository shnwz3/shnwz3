### What I Build

I specialize in engineering production-ready mobile apps, desktop AI software, and high-performance web platforms:

- **Mobile Full-Stack:** Built & scaled a production **Ride-Hailing Platform** with **5,000+ downloads** (real-time dispatch, geospatial routing, driver & rider mobile apps in React Native, Node.js & Docker).
- **Desktop & GenAI:** Creator of **YoType** — a universal AI typing layer for desktop that triggers intelligent `/commands` directly inside any text field across your OS.
- **SaaS & E-Commerce:** Architecting high-converting e-commerce platforms and full-stack SaaS applications with secure payments, authentication, and resilient APIs.
- **Landing Pages & Creative Web:** Crafting award-standard, interactive landing pages with buttery-smooth animations using **GSAP** and **Three.js**.
